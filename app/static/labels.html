// how to print

  1. choose how many labels, and the size.
  2. press print.
  3. in the print window pick letter paper and 100% scale, not "fit to page".
  4. cut along the dashed lines and put one label on each box.

// labels

prints are not recorded on this server.

the large square is the tag the live view reads. the small code opens the same box from any camera app. neither holds the contents, only the number. print at 100% scale on letter paper, matte if possible.
